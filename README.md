D&J Imports — Projeto de Extensão em Desenvolvimento Web

🛍️ D&J Imports — Loja Virtual de Produtos Eletrônicos e Vestuário

🎯 Objetivo do Projeto
O projeto D&J Imports foi desenvolvido como parte de um projeto de extensão
acadêmica, com o objetivo de aplicar na prática os conhecimentos em
desenvolvimento web.

A proposta é simular uma loja virtual voltada para a venda de produtos
eletrônicos, vestuário e acessórios, oferecendo uma navegação intuitiva
e visualmente atrativa para o usuário.

---

🧩 Estrutura do Projeto
O sistema é uma aplicação web estática, organizada em seções bem definidas,
representando as principais áreas de um e-commerce moderno.

A estrutura foi pensada para facilitar a navegação, destacar produtos,
promoções e categorias, além de oferecer uma experiência fluida ao usuário.

---

⚙️ Funcionalidades
- Página inicial com banners promocionais em carrossel
- Listagem de novos produtos
- Seção de produtos em destaque
- Galeria com filtro por categorias
- Área de promoções e ofertas especiais
- Simulação de carrinho de compras
- Área de login de usuário
- Seção de newsletter para novidades
- Rodapé com informações institucionais e contato
- Integração com VLibras para acessibilidade

---

🖥️ Interface e Experiência do Usuário
A interface foi desenvolvida com foco em usabilidade e organização visual,
utilizando ícones, imagens e animações para melhorar a experiência do usuário.

O layout é responsivo e adaptável a diferentes tamanhos de tela, permitindo
uma navegação consistente em desktop e dispositivos móveis.

---

🛠️ Tecnologias Utilizadas
- HTML5 para estruturação das páginas
- CSS3 para estilização e layout responsivo
- JavaScript para interações e dinamismo
- jQuery para manipulação de elementos
- Owl Carousel para criação de banners e sliders
- Font Awesome para ícones
- VLibras para acessibilidade
- Integração preparada para PHP e SQLite

---

🔒 Acessibilidade
- Inclusão do plugin VLibras
- Estrutura semântica em HTML
- Navegação visual clara e organizada

---

🎓 Contexto Acadêmico
Projeto desenvolvido por alunos como atividade prática de extensão,
com foco no aprendizado de desenvolvimento web, organização de layout,
interação com o usuário e boas práticas de front-end.

---

🚀 Considerações Finais
O D&J Imports representa a aplicação prática de conceitos fundamentais
do desenvolvimento web, simulando um ambiente real de e-commerce e
contribuindo para o desenvolvimento técnico e acadêmico dos alunos.
